# 🎓 Student Attendance Tracker

## 📌 Project Overview

The Student Attendance Tracker is a Python-based application developed to manage and track student attendance records efficiently. The system allows users to mark attendance, view records, search for students, and generate attendance reports. Attendance data is stored in a CSV file for easy access and management.

---

## 🎯 Objectives

* To automate attendance management.
* To store attendance records in a structured format.
* To provide attendance statistics and reports.
* To improve understanding of Python programming concepts such as classes, file handling, loops, and data analysis.

---

## ✨ Features

* Mark student attendance (Present/Absent)
* Store attendance records in CSV format
* View all attendance records
* Search attendance by student name
* Generate attendance reports and statistics
* User-friendly menu-driven interface

---

## 🛠 Technologies Used

* Python 3
* Pandas Library
* CSV Module

## ▶️ How to Run

### Step 1: Install Python

Download and install Python 3 from:
https://www.python.org/downloads/

### Step 2: Install Pandas

Open Command Prompt and run:

```bash
pip install pandas
```

### Step 3: Run the Project

```bash
python attendance_tracker.py
```
